# 시연 영상 찍는 방법

차량 · 부모 · 자녀 세 화면을 한 화면에 띄우고, **실제 개발 서버**로 픽업 한 번을 처음부터 끝까지 돌린다.
녹화본이 아니라 세 앱이 서버를 통해 실제로 주고받는 모습(알림 · 화면 전환)을 보여 주는 시연이다.

| 위치 | 기기 | 앱 |
|---|---|---|
| 왼쪽 | Pleos Connect 에뮬레이터 | iLink 차량 앱 (실제 빌드, 서버 연결) |
| 가운데 | iOS 시뮬레이터 (iPhone 17 Pro) | iLink 부모 |
| 오른쪽 | Android 에뮬레이터 | iLink 자녀 |

## 준비 (한 번)

- `ilink-mobile`, `ilink-vehicle` 두 저장소를 같은 폴더에 받는다.
- Pleos Connect 시스템 이미지와 AVD `ilink_pleos` (차량 README의 '앱 실행 방법'), Android 폰 AVD 하나 (`PHONE_AVD=이름`), Xcode.
- 녹화는 macOS '화면 기록' 권한, 창 자동 배치는 '손쉬운 사용' 권한(터미널)이 필요하다.
- 맥 메모리 16GB 이상 권장 (에뮬레이터 2개 + 시뮬레이터).

## 순서

```bash
scripts/demo/up.sh          # 세 기기를 켜고 앱을 새로 설치해 첫 화면에 둔다 (빌드 포함 10분 안팎)
scripts/demo/record.sh      # 녹화 시작 (Ctrl+C로 끝, 바탕화면에 저장)
```

1. **차량 연결 (QR)** — 차량 화면에 QR이 뜬다. 부모 앱 '가족 프로필 등록 → QR 촬영' 화면에서 `scripts/demo/link.sh`
   (시뮬레이터에는 카메라가 없어서, 차량 QR 내용을 부모 iPhone에서 연다) → '차량 정보 확인'.
2. **가족 프로필** — 약관 동의 → 보호자 이름(예: 엄마) → 자녀 이름 → 초대장 화면에서 **편지지를 눌러 링크 복사**
   (편지지를 길게 누르면 '초대장을 전송했어요'로 넘어간다).
   차량 화면은 연결되면 '○○님, 오늘은 예정된 픽업이 없어요'로 바뀐다.
3. **자녀 연결** — `scripts/demo/invite.sh` → 자녀 폰에 초대 화면(C00) → '연결하기' → '연결이 완료되었어요!'
4. **픽업 일정** — 부모 앱 '픽업 일정 등록하기' → 학원 검색 → 시간 · **오늘 요일 포함** → 등록.
   20초 안에 자녀 화면 아래 '다음 픽업 위치 · 시간', 30초 안에 차량 화면에 오늘 픽업이 뜬다.
5. **출발** — 차량 '픽업 시작하기' → '여기로 출발하기'. 자녀 폰에 푸시 알림, 부모 iPhone에 알림 배너 · 잠금화면 Live Activity
   (처음 한 번 '실시간 현황 허용'을 누른다),
   자녀 화면은 '엄마가 출발했어요'. (출발 직후 1.5초 동안은 '합류 안내 보류' 버튼이 눌리지 않는다: 두 번 눌러 보류되는 것을 막는다)
6. **주행** — `scripts/demo/drive.sh` → 차가 1분 동안 목적지로 이동(차량은 주행 중 화면), 도착하면 기어 P로 정차.
7. **합류 안내** — 정차하면 서버가 자녀에게 합류 안내를 보낸다. 자녀 화면이 지도(C03)로 바뀌고 차 · 내 위치가 보인다.
8. **탑승** — `drive.sh`가 이어서 20초 뒤 뒷문을 열고 닫는다 → 탑승 인식 → 10초 뒤 탑승 완료.
   차량 '탑승 완료', 자녀 '안전하게 탑승했어요!', 부모 알림 '탑승 완료'. (두 화면은 8초 뒤 자동으로 대기 화면으로 돌아간다)

중간에 보여 줄 만한 것: 자녀의 '준비 시간이 더 필요해요'(+5분 → 부모 · 차량에 반영), '차를 못 찾겠어요'(부모에게 도움 요청).

```bash
scripts/demo/down.sh        # 끝나면 모두 끄기
```

## 참고

- iOS 원격 푸시는 Firebase iOS 설정(`GoogleService-Info.plist`)과 APNs 키를 받은 뒤 켠다. 그 전까지 부모 iPhone 알림은 앱이 서버 알림 목록(NOTI-02)을 3초마다 확인해 띄운다. 자녀(Android)는 FCM 푸시가 바로 온다.
- 차량 에뮬레이터에는 실제 주행이 없고 Pleos 에뮬레이터는 차량 신호(VHAL) 주입을 막아 두어서, 차량 앱 debug 빌드는
  시연 신호 입력(`SimInput`)으로 위치 · 기어 · 주행 여부 · 문 신호를 받는다. 길안내도 Pleos 내비 대신 흉내 낸다
  (에뮬레이터 내비는 위치가 순간 이동하면 경로 오류 창을 띄우고 앞으로 나온다). 도착 예정 시간은 위치 · 거리로 계산한다.
  그 뒤는 실제 차와 같다: 앱이 서버로 텔레메트리 · 정차 · 문 이벤트를 보내고, 합류 안내 · 탑승 판정은 서버가 한다.
- 한글 이름은 맥 키보드로 직접 입력한다.
- 다시 처음부터 찍으려면 `scripts/demo/up.sh --no-build` (세 앱 데이터를 지우고 새 차량 · 새 가족으로 시작).
